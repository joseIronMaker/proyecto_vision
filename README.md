# Proyecto de visión: percepción para navegación con ROS 2

Actividad integradora del Tema 5 (MPIAF-12 Visión Inteligente). El entregable es el paquete
ROS 2 [`percepcion_nav/`](percepcion_nav/): cámara, detector YOLO con `vision_msgs`,
verificación visual, localización 3D con RGB-D y envío de metas a Nav2.

- Instalación, compilación y ejecución: [percepcion_nav/README.md](percepcion_nav/README.md).
- Especificación, plan y tareas (Spec Kit): [specs/001-paquete-percepcion-nav/](specs/001-paquete-percepcion-nav/).
- Principios del proyecto: [.specify/memory/constitution.md](.specify/memory/constitution.md).

La raíz del repositorio se usa como workspace de colcon (`colcon build` aquí mismo).
